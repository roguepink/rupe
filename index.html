⏸ 止めています
2倍いまの大きさ

使い方

  1. 見たいものに、スマホを 10〜15センチ くらい 近づけます。
  2. 「＋ 大きく」「－ 小さく」で、大きさを かえます。
  3. 暗いときは「💡 ライト」。
  4. 手が ふるえて 読みにくいときは「⏸ 止める」。
    絵が 止まるので、スマホを 楽に持って ゆっくり読めます。
  5. 止めた絵は、指で なぞると 動きます。
    見たい所を 指で 1回 押すと、そこが まん中に来ます。
  6. 「🎨 見やすい色」を押すたびに、
    ふつう → くっきり(白黒) → 黒地に白 → 黒地に黄 と かわります。

うまく見えないとき

  • ぼやける … 近すぎると ピントが合いません。少し はなしてください。
  • 光って 字が見えない … 紙を 少し かたむけるか、ライトを 消してください。
  • ぶれる … ひじを テーブルに つけると ぶれにくくなります。それでも だめなら「止める」。
  • ライトが 使えない … スマホによっては、このアプリから ライトを つけられません。明るい所で 見てください。

カメラが 使えないとき

iPhone(Safari)

  1. 上か下の アドレスの所の「ぁあ」(または「AA」)を押す
  2. 「Webサイトの設定」を押す
  3. 「カメラ」を「許可」にする
  4. このページを 開き直す

Android(Chrome)

  1. アドレスの 左はしの マークを押す
  2. 「権限」または「サイトの設定」を押す
  3. 「カメラ」を オン(許可) にする
  4. このページを 開き直す

LINE の中で 開いているときは、カメラが 使えないことがあります。
右上か右下の メニューから「Safari で開く」(iPhone)・「他のアプリで開く」→ Chrome(Android)を 選んでください。

わからないときは、ご家族に この画面を 見せてください。

ホーム画面に 入れると 便利です

  • iPhone … Safari の 下の「共有」(四角に上むきの矢印)→「ホーム画面に追加」
  • Android … Chrome の 右上「︙」→「ホーム画面に追加」

一度 入れると、次からは アイコンを押すだけで すぐ使えます。
